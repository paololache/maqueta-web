# Maqueta de alcance — sitio web de 3 secciones

Página interactiva (Next.js 16, TypeScript, Tailwind CSS v4 y framer-motion) que muestra al cliente la estructura estándar de su sitio: header, 3 secciones (Inicio, Servicios, Contacto) y footer.

- Vista previa en móvil, tablet y escritorio.
- Selector de paleta de colores y de tipo de hero.
- Panel de alcance con resaltado de cada punto y checklist de validación.
- Botón de WhatsApp que envía la configuración elegida.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
